Place your birthday photos in THIS folder (assets/photos/).

The website loads these image files by default:

  photo1.png
  photo2.png
  photo3.png
  photo4.png
  photo5.png

The code accepts ANY image format — just make sure the filename
extension you use matches the `photos` array in `script.js`.

To add more photos, drop the files here and add the new paths
to the `photos` array at the top of `script.js`, for example:

  "assets/photos/photo6.png",
  "assets/photos/photo7.jpg",

Optional: add a short caption for each photo by editing the
`captions` array in `script.js` (right below the `photos` array).

Recommended: keep file sizes small (under ~500 KB per photo) for
fast loading, especially on mobile devices.
